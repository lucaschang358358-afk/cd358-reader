# CD-358 輕量純按鍵電子書閱讀器 (Project Muteki)

專為 **無敵 Besta CD-358** 小螢幕、純實體按鍵操作設計的輕量離線電子書閱讀器。

## 特色重點
1. **100% 保留原版 PDF 閱讀引擎與閱讀邏輯**：完整沿用原版 `pdf_engine.c`、`book_loader.c` 及壓縮／解碼核心，支援 PDF 原版渲染、5 段縮放（適應整頁 / 適應寬度 / 135% / 175% / 225%）、方向鍵平移與自動翻頁、文字重排檢視、目錄、書籤與全文搜尋。
2. **純實體按鍵操作（完全關閉觸控輪詢）**：已移除所有觸控螢幕監聽，即使觸控面板損壞也不會誤觸；所有 PDF 縮放、平移、書架管理與選單都可直接用實體按鍵完成。
3. **小螢幕自適應輕量排版**：自動偵測實機解析度（320×240 / 480×320 / 800×480）與像素格式（RGB565 / XRGB8888），採用單欄緊湊書架與全螢幕沉浸閱讀模式，並移除統計、RPG、成就等額外負擔以節省 RAM。

## 透過 GitHub Actions 編譯並安裝至 CD-358
1. 將本資料夾內容上傳至你的 GitHub 倉庫（確認包含 `.github/workflows/build-muteki.yml`）。
2. 進入 GitHub 倉庫的 **Actions** 頁籤，等待 **Build CD-358 Muteki Reader** 跑完（或手動點 `Run workflow`）。
3. 下載 Artifacts 中的 **`cd358-reader-muteki-exe`**，裡面會包含兩個版本：
   - `cd358-reader-arm7.exe`（通用相容版，建議優先放這支測試）
   - `cd358-reader-arm9.exe`（ARM9 最佳化版）
4. 將 `.exe` 複製到 CD-358 內建磁碟即可執行。

## 純按鍵操作一覽

### 書架畫面
| 按鍵 | 功能 |
| :--- | :--- |
| `↑` / `↓` / `PgUp` / `PgDn` | 選擇書籍或資料夾 |
| `Enter` / `Space` | 開啟書籍 / 進入資料夾 |
| `O` | 開啟檔案選擇器匯入新書（PDF / EPUB / TXT / PNG / BMP） |
| `F` | 循環切換格式篩選（全部 / EPUB / PDF / TXT / 圖片） |
| `N` | 新增資料夾 |
| `V` | 將目前選取的書籍移至資料夾 |
| `D` | 從書架移除選取的書籍或資料夾（含二次確認） |
| `T` | 快速切換 12 套日夜佈景主題 |
| `Tab` 或 `2` | 切換至「主題與排版設定」分頁（按 `1` 或 `Tab` 返回書架） |
| `H` | 查看按鍵說明與實機解析度／鍵碼資訊 |
| `Backspace` / `ESC` | 在資料夾內返回上層；在根目錄按 `ESC` 顯示離開確認 |

### PDF 閱讀畫面（完整保留原版邏輯＋純按鍵縮放）
| 按鍵 | 功能 |
| :--- | :--- |
| `Z` / `+` / `=` | **放大**（適應整頁 → 適應寬度 → 135% → 175% → 225%） |
| `X` / `-` | **縮小** |
| `0` | 一鍵重置為「適應整頁」 |
| `↑` `↓` `←` `→` | 放大時平滑移動視角；未超出邊界或移至邊界時自動翻頁 |
| `PgUp` / `PgDn` / `Space` | 直接上一頁 / 下一頁 |
| `R` | 切換 PDF 原版檢視 / 文字重排檢視 |
| `I` | 切換**全螢幕沉浸模式**（隱藏上下工具列，讓小螢幕畫面最大化） |
| `M` / `ESC` | 開啟閱讀選單（也可在選單內用左右鍵調縮放） |
| `C` / `G` / `K` / `F` | 章節目錄 / 跳頁（支援直接打數字） / 書籤 / 全文搜尋 |
| `T` / `A` / `B` | 切換主題 / 自動翻頁 / 返回書架 |

### EPUB / TXT / 圖片書閱讀畫面
| 按鍵 | 功能 |
| :--- | :--- |
| `←` `↑` `PgUp` / `→` `↓` `PgDn` `Space` | 上一頁 / 下一頁 |
| `Z` (`+`) / `X` (`-`) | 調整字體大小 |
| `L` / `T` / `I` / `A` | 切換行距 / 切換主題 / 全螢幕 / 自動翻頁 |
| `C` / `G` / `K` / `F` / `M` / `B` | 目錄 / 跳頁 / 書籤 / 搜尋 / 閱讀選單 / 返回書架 |
